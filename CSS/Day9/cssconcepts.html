CSS (Cascading Style Sheets)

CSS stands for Cascading Style Sheets. It is used to style and design web pages. CSS controls colors, fonts, spacing, layouts, responsiveness and animations.

Why CSS is Used?

  • Add colors to web pages
  • Change fonts and text styles
  • Create layouts
  • Add animations and effects
  • Make websites responsive

Example:

This box is styled using CSS.

1. Inline CSS

Inline CSS is used to style a specific HTML element using the style attribute inside the opening tag. It affects only that element and has the highest priority.

Example:

This box uses Inline CSS.

2. Internal CSS

Internal CSS is written inside the style tag within the head section of an HTML document. It is useful when styling a single page.

Example:

This box uses Internal CSS.

3. External CSS

External CSS is written in a separate CSS file and linked using the link tag. It is the most commonly used CSS method in real-time projects.

Example:

This box uses External CSS.

CSS Priority

When multiple CSS rules are applied to the same element, CSS follows a priority order.

  • Inline CSS (Highest)
  • Internal CSS
  • External CSS
