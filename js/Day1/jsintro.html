JavaScript Variables

1. What is a Variable?

A variable is a container used to store data values in JavaScript. Variables can hold numbers, strings, objects, arrays, and more.

2. What is Declaration?

Declaration means creating a variable using keywords such as var, let, or const. 

let studentName;

3. What is Initialization?

Initialization means assigning a value to a variable. 

let studentName = "Bala";

4. What are the 3 Types of Variable Keywords?

  • var - Old way of declaring variables.
  • let - Modern variable declaration with block scope.
  • const - Used for constant values that cannot be reassigned.

5. What is the Compiler in JavaScript and its Name?

JavaScript is primarily interpreted and executed by a JavaScript Engine. Different browsers use different engines:

  • Google Chrome - V8 Engine
  • Mozilla Firefox - SpiderMonkey
  • Safari - JavaScriptCore
  • Microsoft Edge - V8 Engine

6. What are Printing Statements?

Printing statements are used to display output in JavaScript.

  • console.log() - Prints output in the browser console.
  • document.write() - Prints output on the webpage.
  • alert() - Displays output in a popup box.
console.log("Hello World");
document.write("Hello World");
alert("Hello World");
