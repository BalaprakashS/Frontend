Frontend Interview Bug Fixing Tasks - Answers

Task 1 - CSS Center Alignment Bug

Question

Hello should be centered inside the box. Find all missing properties. 

<div class="box">Hello</div>

.box{
    width:200px;
    height:200px;
    justify-content:center;
    align-items:center;
}

Answer

The justify-content and align-items properties work only with Flexbox. Add display:flex. 

.box{
    width:200px;
    height:200px;
    display:flex;
    justify-content:center;
    align-items:center;
}

Task 2 - Flex Direction Bug

Question

Items should display in a row. Fix the invalid value. 

display:flex;
flex-direction:rows;

Answer

The value rows is invalid. Use row instead. 

display:flex;
flex-direction:row;

Task 3 - Grid Bug

Question

Create a grid with 3 equal columns. Find the typo. 

display:grid;
grid-template-column:repeat(3,1fr);

Answer

The property name is incorrect. Use grid-template-columns. 

display:grid;
grid-template-columns:repeat(3,1fr);

Task 4 - Position Bug

Question

The badge appears in the browser corner. Fix the card. 

<div class="card">
    <span class="badge">New</span>
</div>

.badge{
    position:absolute;
    top:0;
    right:0;
}

Answer

The parent element needs position:relative. 

.card{
    position:relative;
}

.badge{
    position:absolute;
    top:0;
    right:0;
}

Task 5 - Media Query Bug

Question

Responsive styles are not working. Find the error. 

@media(max-width:768){
    .card{
        width:100%;
    }
}

Answer

The media query is missing the px unit. 

@media(max-width:768px){
    .card{
        width:100%;
    }
}

Task 6 - Bootstrap Grid Bug

Question

All cards should appear in the same row. Find the grid issue. 

<div class="row">
    <div class="col-3">1</div>
    <div class="col-3">2</div>
    <div class="col-3">3</div>
    <div class="col-6">4</div>
</div>

Answer

Bootstrap rows contain 12 columns. Current total is 15 columns. Change the last column to col-3. 

<div class="row">
    <div class="col-3">1</div>
    <div class="col-3">2</div>
    <div class="col-3">3</div>
    <div class="col-3">4</div>
</div>

Task 7 - Bootstrap Navbar Bug

Question

The collapse button exists but the menu does not open. Add the missing class. 

Navbar code missing a required class.

Answer

Add the navbar-collapse class. 

<div class="collapse navbar-collapse" id="navbarNav">
</div>

Task 8 - Bootstrap Modal Bug

Question

The modal and button exist but the modal does not open. Find the missing Bootstrap file. 

Modal is not opening.

Answer

Bootstrap JavaScript bundle is required. 

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>

Task 9 - Bootstrap Card Bug

Question

The image is not responsive. Add the required Bootstrap class. 

<img src="img.jpg">

Answer

Use the img-fluid class. 

<img src="img.jpg" class="img-fluid">

Task 10 - Tailwind Responsive Grid Bug

Question

Grid should display: Mobile = 1 column Tablet = 2 columns Desktop = 3 columns 

<div class="grid grid-cols-3">

Answer

Add responsive Tailwind classes. 

<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3">
</div>

Task 11 - Tailwind Hover Bug

Question

Zoom effect should happen only on hover. 

<button class="bg-blue-500 scale-110">

Answer

Use the hover prefix. 

<button class="bg-blue-500 hover:scale-110">
</button>

Task 12 - Tailwind Shadow Bug

Question

Shadow is not working. Find the invalid class. 

<div class="bg-white shadow-20">

Answer

shadow-20 is invalid. Use shadow or shadow-lg. 

<div class="bg-white shadow-lg">
</div>

Task 13 - Tailwind Image Bug

Question

The image is stretched. Add the missing class. 

<img src="img.jpg" class="w-full h-64">

Answer

Use object-cover. 

<img src="img.jpg" class="w-full h-64 object-cover">

Task 14 - Tailwind Dropdown Bug

Question

Dropdown is not opening. Add the required class. 

<li class="group">
    Courses
    <ul class="hidden">
        <li>HTML</li>
    </ul>
</li>

Answer

Add group-hover:block. 

<li class="group">
    Courses
    <ul class="hidden group-hover:block">
        <li>HTML</li>
    </ul>
</li>

Task 15 - Mixed CSS + Bootstrap + Tailwind Bug

Question

Find: 1. Bootstrap mistake 2. Tailwind mistake 3. Structure mistake 

<div class="container row">
    <div class="col-lg-4 grid-cols-3">
        Card
    </div>
</div>

Answer

The row should be inside the container. The grid-cols-3 class requires grid. The column should be inside a row. 

<div class="container">
    <div class="row">
        <div class="col-lg-4">
            <div class="grid grid-cols-3">
                Card
            </div>
        </div>
    </div>
</div>
